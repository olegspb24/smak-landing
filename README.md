# SMAK — лендинг

Одностраничный лендинг продукта **SMAK** — пасты-концентрата для супов и горячих блюд
(с витамином B12). Ориентирован на розничные сети и маркетплейсы.

## Стек

Статический сайт без сборки: чистый HTML + CSS, интерактивные графики — отдельные
HTML-страницы с ECharts (встроены в `index.html` через `<iframe>`).

```
index.html    разметка страницы
style.css     стили
assets/       изображения (герой, сравнения типографики и вёрстки)
charts/       три интерактивных графика (ECharts, офлайн) + исходные данные data.csv
fonts/        PT Sans / PT Serif в woff
_headers      правила кэширования для хостингов, поддерживающих этот формат
```

## Локальный просмотр

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/

## Деплой

Публикуется через **GitHub Pages** из ветки `main` (корень репозитория):
`https://<username>.github.io/<repo>/`

Файл `_headers` на GitHub Pages игнорируется — это заготовка для Netlify /
Cloudflare Pages, если понадобится переехать на CDN с управляемым кэшированием.
